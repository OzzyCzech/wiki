ego(lite) is a Chromium-based browser for everyday browsing and AI-driven web automation, including scraping websites behind a login.

## Agent integration

- The **ego-browser** skill connects coding agents such as Claude Code, Codex, Cursor and Hermes Agent to the browser.
- After onboarding, invoke `/ego-browser` in the agent and describe the task.
- Agents work in separate **Spaces**, without taking over the mouse or the user's tabs unless explicitly handed over.

## Browser features

- Imports Chrome profiles and reuses existing website logins.
- Semantic snapshots cover cross-origin iframes, shadow DOM and embedded widgets.
- Bookmarks, passwords, cookies and browsing history are stored locally.
